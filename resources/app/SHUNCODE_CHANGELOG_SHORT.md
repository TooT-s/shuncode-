# ShunCode 0.8.1 更新日志（简版）

**日期：** 2026-10-01　|　**平台：** Windows x64、macOS Apple Silicon、Linux x64　|　**对比：** 0.8.0

**补充更新：** 2026-10-04（10-03 的历史条目保留当时状态；旧同版本包不含新变更）

## 2026-10-04 任务展示栏高度可拖动（新一轮出包）

- **GitHub Authentication 最小诊断一并交付：** 不再把普通连接错误误报为用户未完成授权；明确代理、DNS／证书、回调超时与设备码超时按证据区分，日志不输出敏感字段。不自动改代理、系统 DNS、TLS 或登录方式；用户设备尚需自行复测。
- **任务展示栏高度可拖动：** 在 Chat／Bridge 任务区下边缘向下拖动扩展，保留原聊天和 MCP 控制最小空间；方向键调整、Home／双击恢复默认，折叠后不占高度、展开恢复。三端隔离浏览器定向回归各 5/5、TypeScript 检查通过；正式打包（含 Windows `-SkipTests`、Linux DEB 复用路径）强制跑新回归并核对包内 JS／CSS。旧同版本包及已安装客户端不包含本次修改；新包需核验日志和 SHA-256，不代安装。Windows／Linux 新包还需包含此前 GitHub 登录诊断，真实用户登录仍待自行复测。

- **2026-10-03 API 地址与模型选择器后续修复（尚未重新出包）。** Chat Completions／Responses 共用 Base URL 归一化，根地址、`/v1`、`/v1/` 与自定义前缀均有本地模拟回归；“测试”仅检查 `GET /models`，真实聊天 POST 另由 Agent Host 模拟服务验证。失败日志显示脱敏 endpoint、状态和 Content-Type，不包含 Key 或 HTML 正文。模型按渠道分组，渠道及组内模型可持久化拖拽排序，搜索不改排序、新模型追加末尾、选中项不被滚动条遮挡；麦克风状态、错误提示与顶部／中间／底部渠道右键菜单均有定向回归。三端 38/38 定向测试已通过，但未使用真实 Key／真实网关，也未验收安装版。
- **正式打包门禁与旧包边界。** Mac DMG、Windows Setup（包括 `-SkipTests`）、Linux tar.gz／DEB 将运行 API `/models`、实际模拟 Chat／Responses 与聊天 UI 回归；生产 bundler 校验 URL helper 和 Agent Host 处理被带入扩展运行时，DEB 复用包仍检查。2026-10-02 已生成的 0.8.1 旧包**不包含**这次后续源码、脚本及更新日志；本轮未出新包、未安装、未部署。交付须重新出包并校验包内双版日志和新 SHA-256。

- **启动 Bridge 不再要求手动刷新授权。** 已登录但页面尚未显示授权时，点击“启动 Bridge”会先在线刷新授权；确认有效后再启动。
- **安全检查不放宽。** 未登录时只提示先登录；授权未通过、网络错误或超时均不启动，也不依赖本地缓存放行。Bridge 后端启动前仍会独立在线校验。运行中的签名授权未到期临时断网保活规则沿用 0.8.0。
- **支付状态提示更准确。** 已支付且权益确实到期的旧订单不再误显示为“正在同步”；仅在明确无有效权益时允许重新选购。新近已支付但服务端仍报告无权益时，仍禁止重复付款，并提示联系支持核对订单与账号。客户端不会自行补发权益。
- **订单三分钟支付窗口＋30 秒缓冲（三端源码）。** 实际支付入口截止为创建后 3 分 30 秒；三端 Worker 的订单查询即时判断、每分钟定时清理，已验签的迟到付款仍履约。三端打包入口新增不可跳过的 Worker 源码与测试门禁；此前已执行一次 0.8.1 三端顺序打包，但桌面打包不会自动部署 Worker，本轮也没有部署 Worker。
- **API 供应商支持两种请求协议与安全自动协商（三端新源码）。** 新增／编辑表单可选择 Chat Completions（旧配置默认）、Responses 或自动。自动模式在首次真实请求优先走同一网关的 `/v1/responses`，仅遇 404／405／501 且尚未输出时回退 `/v1/chat/completions`；不额外发送能力探测请求，401／403、429、其他 5xx、超时和 HTML 200 均不回退。JSON 导入支持自动模式；已存 API Key 可保持不变地编辑配置。表单“测试”只检查 `GET /models`，不保证聊天接口可用。
- **聊天布局与队列交互（三端源码）。** 借鉴 Devin 对聊天内容和操作区的信息层级，而非复制其品牌界面：输入栏优先使用发送按钮之外的剩余宽度展示模型名，空间不足时先收起模式文字、最后再收起模型文字；配置与模型的紧凑图标各占独立位置。长配置名截断，用户消息与助手正文在宽窗口下更易阅读，长链接可换行。编辑排队消息仍显示发送箭头并按原队列顺序提交，不中断正在生成的回复；模型列表和错误提示不展示 API 地址或大段 HTML/data: 内容。协议选项与自动回退规则不变。正式打包入口新增不可跳过的聊天 UI 源码回归门禁；本轮未生成新包，尚未做安装版视觉验收。
- **2026-10-02 模型菜单宽度修正（三端后续源码）。** 模型菜单不再被整行的上下文、输出和价格说明撑到接近窗口宽：上限 560px，较窄窗口还会按视口留边收窄；优先显示模型名，过长的说明在当前行截断，保留搜索、完整无障碍描述及悬浮的详情。三端源码与定向回归已更新；此修改晚于当天 Mac → Windows → Linux 的正式打包，**不在那一批 0.8.1 安装包内**，且尚未做安装版视觉验收。
- **Mac 截图核验：模型列表成功不等于发送成功。** 截图中能加载 44 个模型，但聊天返回 `Model endpoint returned non-JSON (200)` 和 HTML 页面，说明模型请求收到了网页而非模型 JSON／SSE；不能仅凭截图判断具体网关路径、密钥或模型问题。Mac 当前 `/Applications/ShunCode.app` 版本实测为 **0.8.0**，无新协议选项；本地模拟请求复现 HTML 200，并验证新源码自动模式可走 Responses，但没有使用真实 Key 测试该网关。
- **三端版本统一升至 0.8.1。** Code-OSS 基线仍为 1.136.1；详细技术与历史记录见 `docs/mcp-changelog-0.8.1-2026-10-01.md`。

- **2026-10-02 Mac Bridge 健康检查排版（后续源码）。** 左下栏健康结果改为在连接元信息下方独立成行，与 Windows 的布局对齐；正常／异常有状态点，长摘要可在窄侧栏内换行，无结果时隐藏。不改动健康探测和授权逻辑。Windows/Linux 无健康 UI 改动；此 Mac 修复与两版日志更新均不在先前的 0.8.1 安装包内，本轮未重新打包、覆盖安装或做安装版视觉验收。

- **2026-10-02 API 渠道与协议编辑优化（三端后续源码）。** 多渠道模型列表显示精简的“渠道名 / 模型名”；旧渠道名若为完整 URL，仅显示主机名，同名渠道附序号，不向选择器展示整条 API 链接。新建渠道默认“自动（默认）：优先 Responses，端点不支持时回退 Chat”，旧配置缺少协议字段时仍按原 Chat 处理。显式 Chat／Responses 在标准根地址或 `/api` 后补齐 `/v1`，已有 `/v1` 不重复；自动模式无 `/v1` 时沿用原根路径，保留既有兼容性。编辑原渠道的路径或切换请求协议可继续使用已存密钥；更换网址协议、域名或端口必须重输密钥，避免发送给新来源。“测试”仍只检查模型列表，未用真实网关验证聊天接口。上述仅是新源码，不在旧 0.8.1 安装包中。

- **2026-10-02 支付窗口与公开首页（三端后续源码）。** Worker 首页不再把支付用户跳转到 `/admin`；点击结算启动页的按钮会在独立窗口打开原有支付流程，启动页用支付链接令牌查询订单状态。仅确认已付款或未付款已过 3 分 30 秒时才尝试自动关闭；浏览器或第三方网页限制可能使自动关闭失败，需手动关闭。过期订单保留、不会当作已付款或自动授予权益，验签迟到付款仍可履约。三端 Worker 源码测试通过；未做真实付款、部署、重新打包或安装。

- **2026-10-02 打包脚本新增支付结算门禁（三端后续源码）。** Mac DMG、Windows Setup（含跳过一般测试模式）、Linux tar.gz 与 DEB 正式入口均须检查公开首页不跳后台、令牌状态接口、受控窗口、仅支付成功或过期才尝试关窗、Windows 原支付跳转，并运行本地支付回归。旧的 210 秒订单期限和验签回调门禁继续保留。门禁源码已单独核验；未执行完整打包、安装或部署 Worker。

- **2026-10-02 任务卡流程中文化（三端后续源码）。** MCP 任务工具的可见标题和回执、任务卡固定界面文案改为中文；工具规则要求新步骤、阶段和进度使用简体中文，英文界面中的任务卡固定文案也保持中文。协议字段／状态枚举不变；历史或客户端自行发送的英文自由文本不会被自动翻译。Mac DMG 和 Linux DEB 的复用路径新增无需安装依赖的中文源码门禁，Windows Setup（含 `-SkipTests`）和 Linux tar.gz 构建执行含任务回归的完整门禁；Mac 的完整构建路径亦执行回归。仅更新源码、打包脚本、测试和日志，未实际重新打包或安装。 三端中文门禁的源检与对应测试已通过，Mac 任务／修复／布局合并测试 41/41；未执行正式打包或安装。
